pub(crate) fn fibonacci(n: u64) -> u64
Expand description

Returns the nth Fibonacci number, counting from F(0) = 0.

F(0) = 0, F(1) = 1, and every number after is the sum of the two before it: F(n) = F(n-1) + F(n-2)

How it works: we only ever keep the last two numbers, prev and curr, and slide them forward one step per loop. After n steps, prev holds F(n).
