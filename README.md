# rust-learning-log

Six months of daily Rust, starting 12 October 2026.

The rule: show up every day for at least 25 minutes. Missing one day happens. Missing two in a row doesn't.

## The plan

| Weeks | Phase       | What                                   |
| ----- | ----------- | -------------------------------------- |
| 1–12  | Foundations | The Rust Book + Rustlings              |
| 13–18 | Practice    | Exercism Rust track, a small CLI tool  |
| 19–26 | Build       | A real project, shipped and written up |

Daily progress lives in [LOG.md](LOG.md).

## Layout

```
book/        projects from The Rust Book (guessing_game, minigrep, ...)
rustlings/   Rustlings exercises
exercism/    Exercism solutions
projects/    anything bigger
```
